# 未解決の項目 — {{PRODUCT_NAME}}

まだ決まっていない要件や疑問を書きためるハブ。文書やコードを書いている途中で決められないことが出たら、その場で追記する。

ここで扱うのは**値・形式・方式といった設計の詳細**。機能を持つ / 持たないは `vision.md` で決める。

## 書き方

- 番号は `OQ-` に 3 桁の連番を付ける。一度付けた番号は使い回さない。
- 新しい項目は「未解決」の節の末尾に足す。本文からは「未確定(`OQ-NNN`)」で参照する。
- 解決したら、項目を「解決済み」の節へ移し、状態を「解決」にして、決定(`D-XXXX`)へのリンクを書く。結論そのものはここに再掲しない(決定と、反映した仕様が持つ)。
- 決めないことにした項目は、状態を「取り下げ」にして理由を 1 行書き、「解決済み」へ移す。
- 項目は消さない。

項目の形は次のとおり。

```markdown
### OQ-000

- 問い: (何が決まっていないか)
- 状態: 未解決 / 解決 / 取り下げ
- 起票: YYYY-MM-DD、Issue #番号(あれば)
- 影響: (決まらないと進められないもの。仕様のファイルや Issue)
- 選択肢: (分かっていれば。推奨があれば「(推奨)」を付ける)
- 決定: (解決したら `D-XXXX` へのリンク)
```
